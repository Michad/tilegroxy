== Description

These connections are used by certain providers, analytics modules, caches, authentication, and rate limiting.  Each datastore definition creates a connection pool when the application is running.

Like other entities, the datastores configuration uses a parameter called `name` to dictate the type of datastore which controls the specific list of configuration parameters available. Every datastore configuration must also have an `ID` defined which can be any string and is used by a corresponding provider, analytics, cache, authentication, or rate limit configuration, usually as a `datastore` parameter.
