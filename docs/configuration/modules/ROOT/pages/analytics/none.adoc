= None
:page-aliases: operation::configuration/analytics/none.adoc
:description: Disables analytics.  Since analytics is off by default this is mainly useful for temporarily disabling a destination without removing its configuration.
:page-eyebrow: Analytics
:page-config-name: none

NOTE: The `id`, `fields`, `extraFields` and `batch` parameters common to every analytics module are still accepted and validated but have no effect.
