= Composite MLT
:page-aliases: operation::configuration/provider/compositemlt.adoc
:description: Combines the layers of MapLibre Tiles (MLT) from multiple providers into one tile.
:page-eyebrow: Provider
:page-config-name: compositemlt
:page-tags: MLT
:page-related: provider/index.adoc[Provider Overview], provider/compositemvt.adoc, provider/cropmlt.adoc, provider/blend.adoc

== Description

If given one child provider that returns an MLT with layer "a" and another that returns an MLT with layer "b", this provider will return an MLT with layers "a" and "b".  The contents of the MLTs are not changed in any way.

NOTE: This is the MLT equivalent of the xref:provider/compositemvt.adoc[compositemvt] provider. MVT and MLT can't be mixed in one tile, so a child known to produce MVT, such as xref:provider/postgismvt.adoc[postgismvt], is rejected when the configuration is loaded.

== Example
[tabs]
====
YAML::
+
[,yaml]
----
provider:
  name: compositemlt
  providers:
  - name: pmtiles
    file: /data/basemap.pmtiles
  - name: proxy
    url: https://tiles.example.com/overlay/{z}/{x}/{y}.mlt
----

JSON::
+
[,json]
----
{
  "provider": {
    "name": "compositemlt",
    "providers": [
      {
        "name": "pmtiles",
        "file": "/data/basemap.pmtiles"
      },
      {
        "name": "proxy",
        "url": "https://tiles.example.com/overlay/{z}/{x}/{y}.mlt"
      }
    ]
  }
}
----
====
