= Crop
:page-aliases: operation::configuration/provider/crop.adoc
:description: Crops raster tiles from a primary provider to a specific geographic area and displays tiles from a secondary provider in the remaining areas.
:page-eyebrow: Provider
:page-config-name: crop
:page-related: provider/index.adoc[Provider Overview], provider/fallback.adoc, provider/cropmvt.adoc, authentication/jwt.adoc, operation::examples/regional-imagery.adoc

== Description

This provider is similar to the bounds parameter in the xref:provider/fallback.adoc[] provider but specific to raster tiles. It provides a cleaner edge when zooming in and out but has greater overhead due to the image processing that occurs. 

== Example
[tabs]
====
YAML::
+
[,yaml]
----
provider:
  name: crop
  bounds:
    south: 51
    north: 63
    west: -7
    east: 0.1
  primary:
    name: proxy
    url: https://tile.openstreetmap.org/{z}/{x}/{y}.png
  secondary:
    name: static
    color: "0000"
----

JSON::
+
[,json]
----
{
  "provider": {
    "name": "crop",
    "bounds": {
      "south": 51,
      "north": 63,
      "west": -7,
      "east": 0.1
    },
    "primary": {
      "name": "proxy",
      "url": "https://tile.openstreetmap.org/{z}/{x}/{y}.png"
    },
    "secondary": {
      "name": "static",
      "color": "0000"
    }
  }
}
----
====

== Configuration

.Configuration options
[cols="1m,3,1,1,1"]
|===
| Parameter | Description | Type | Required | Default

| primary
| The provider of the imagery to crop
| Provider
| Yes
| None

| secondary
| The provider to supply the imagery to use in areas that are cropped out
| Provider
| No
| Fully transparent pixels

| bounds
| Any pixels that fall outside these geographic bounds (in WGS-84/EPSG:4326) will be removed.
| Object with north, south, east, west
| No
| Whole world

| boundsFromAuth
| If true, use the bounds supplied via the auth context such as the geohash claim in xref:authentication/jwt.adoc[JWT] auth.  If no bounds are specified via auth context then it falls back on the bounds parameter.
| bool
| No
| No

|===
