= None
:page-aliases: operation::configuration/ratelimit/none.adoc
:description: Disables rate limiting.  Since rate limiting is off by default this is mainly useful for temporarily turning it off.
:page-eyebrow: Rate Limit
:page-config-name: none

NOTE: The options common to every store, including `policies`, are still accepted and validated but have no effect.  Layers referring to a policy must still name one that exists.
