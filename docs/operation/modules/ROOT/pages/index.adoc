== One unified gateway for accessing all of your map imagery.

[.lead]
Tilegroxy shines when your application consumes geospatial data from multiple sources.
Instead of being tied to a specific backend, it can pull data from any protocol, whether the standard initialisms or a proprietary, authenticated API.
Tilegroxy allows you to provide access to all your maps through a single entry point with uniform authentication, caching, CORS rules, logging, and tracking, all while protecting your keys and upstream providers.

.tilegroxy.yml
[tabs]
====
YAML::
+
[,yaml]
----
server:
  production: false
layers:
  - id: osm
    provider:
      name: proxy
      url: https://tile.openstreetmap.org/{z}/{x}/{y}.png
----

+
[,json]
----
{
  "server": { "production": false },
  "layers": [

      "id": "osm",

    }

== Features

[.features]
--
.Sources
* xref:configuration/provider/proxy.adoc[Proxy] to ZXY, WMS, TMS, WMTS, or other protocol map layers
* Raster tiles plus Mapbox Vector Tile (MVT) and MapLibre Tile (MLT) vector formats
* xref:configuration/provider/cgi.adoc[Act as an HTTP server] for https://www.mapserver.org[MapServer] and other CGI tile generators
* xref:extensibility.adoc[Custom providers] for non-standard and proprietary imagery sources

.Transform
* Tweak raster layers with xref:configuration/provider/effect.adoc[18 standard effects] or your own xref:configuration/provider/transform.adoc[pixel-level logic]
* Combine xref:configuration/provider/blend.adoc[raster] or xref:configuration/provider/compositemvt.adoc[vector tile] layers
* Supports xref:tilejson.adoc[TileJSON]

.Cache
* Cache tiles in xref:configuration/cache/disk.adoc[disk], xref:configuration/cache/memory.adoc[memory], xref:configuration/cache/s3.adoc[s3], xref:configuration/cache/redis.adoc[redis], and/or xref:configuration/cache/memcached.adoc[memcached]
* Commands for xref:commands/seed.adoc[seeding] and xref:commands/test.adoc[testing] your layers

.Secure
* Require authentication using xref:configuration/authentication/static_key.adoc[static key], xref:configuration/authentication/jwt.adoc[JWT], xref:configuration/authentication/passthrough.adoc[an existing HTTP endpoint], xref:configuration/authentication/bearer.adoc[API keys in a database], or xref:configuration/authentication/custom.adoc[custom] logic
* xref:configuration/authentication/jwt.adoc[Restrict access] to a layer and/or geographic region by auth token
* xref:ratelimit.adoc[Rate limit] users, tenants, or IP addresses, from per-second bursts to monthly quotas
* Run as xref:configuration/encryption.adoc[HTTPS], including Let's Encrypt (ACME)
* Minimal HTTP footprint to decrease security exposure

.Operate
* Configurable via file or etcd with xref:configuration.adoc#conventions[environment variable] override, xref:configuration/secret/index.adoc[externalizable secrets], and xref:reloading.adoc[zero-downtime reload]
* xref:get-it.adoc#docker[Container deployment]
* Traces, metrics, and logs via xref:configuration/telemetry.adoc[OpenTelemetry]
* Per-layer usage xref:configuration/analytics/index.adoc[analytics] to ClickHouse, PostgreSQL, or a custom destination
* Usable as an application or a xref:extensibility.adoc[library]
