= Derived Terrain Layer
:description: Some layers encode data in their pixel values rather than showing an image directly.  The Mapbox Terrain-RGB layer stores elevation as a number spread across the red, green, and blue channels.  This configuration decodes it, converts elevation into average air pressure, and renders the result in grayscale, then lays it over OpenStreetMap.
:page-eyebrow: Example

IMPORTANT: Using the Terrain-RGB layer requires a link:https://www.mapbox.com/[Mapbox] access token, supplied through the `MAPBOX_KEY` environment variable.

== Try it

[,shell]
----
export MAPBOX_KEY=your-token
tilegroxy test -c terrain.yml
tilegroxy serve -c terrain.yml
----

The xref:commands/test.adoc[test] command confirms all three layers generate before you start the server.  Be mindful of the OpenStreetMap https://operations.osmfoundation.org/policies/tiles/[tile usage policy].
