= Composite MLT
:description: Allows you to combine MapLibre Tiles (MLT). If given one child provider that returns an MLT with layer "a" and another that returns an MLT with layer "b", this will return an MLT with layers "a" and "b".  The contents of the MLTs are not changed in any way.
:page-eyebrow: Provider
:page-config-name: compositemlt
:page-tags: MLT

NOTE: This is the MLT equivalent of the xref:configuration/provider/compositemvt.adoc[compositemvt] provider. MVT and MLT can't be mixed in one tile, so a child known to produce MVT, such as xref:configuration/provider/postgismvt.adoc[postgismvt], is rejected when the configuration is loaded.

== Example
[tabs]
====
YAML::
+
[,yaml]
----
provider:
  name: compositemlt
  providers:
  - name: pmtiles
    file: /data/basemap.pmtiles
  - name: proxy
    url: https://tiles.example.com/overlay/{z}/{x}/{y}.mlt
----

JSON::
+
[,json]
----
{
  "provider": {
    "name": "compositemlt",
    "providers": [
      {
        "name": "pmtiles",
        "file": "/data/basemap.pmtiles"
      },
      {
        "name": "proxy",
        "url": "https://tiles.example.com/overlay/{z}/{x}/{y}.mlt"
      }
    ]
  }
}
----
====

== Configuration

.Configuration options
[cols="1m,3,1,1,1"]
|===
| Parameter | Description | Type | Required | Default

| providers
