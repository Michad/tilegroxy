= PMTiles

Serves tiles out of a link:https://docs.protomaps.com/pmtiles/[PMTiles] archive. A PMTiles archive is a single file holding a whole tileset, addressed entirely by byte range. This provider works either with a local file or via HTTP(s).

Archives containing MVT, PNG, JPEG, WebP, or AVIF tiles are supported. Archives of any other tile type, such as MLT, fail at startup. Brotli or zstd compression are *not* supported. The `Content-Type` of every tile comes from the tile type in the archive header.

The archive is treated as immutable and static, the file and URL won't work with request-time parameters. Replacing the file underneath a running tilegroxy is not supported and will lead to undefined behavior.

We pull minzoom, maxzoom, bounds, center, and datatype from the archive header, and description, attribution, version, and vector_layers from the archive's metadata. Setting these fields on the xref:configuration/layer.adoc[layer] overrides the values taken from the archive. If you set `bounds` on the layer you must also set `datatype`, since the layer decides how to crop before the archive is opened.

When using a URL the xref:configuration/client.adoc[client] `MaxLength` limits the size of every section read from the archive and the size of each tile after decompression. Archives with dense vector tiles may need a higher limit. Local files have no such limit. The client `UserAgent`, `Headers`, and `Timeout` apply to each range request. The `StatusCodes`, `ContentTypes`, and `UnknownLength` checks don't apply; the server must answer each range request with a 206.

Archives often leave out empty tiles, such as open ocean. A request for a tile that isn't in the archive is treated as out of bounds and returns the xref:configuration/error.adoc[out of bounds error]. Wrap this provider in a xref:configuration/provider/fallback.adoc[fallback] if you want another provider to fill those gaps. 

Name should be "pmtiles"

Configuration options:

[cols="1,3,1,1,1"]
|===
| Parameter | Description | Type | Required | Default

| file
| The path to a PMTiles archive on the local filesystem. Mutually exclusive with `url` and required if `url` is undefined
| string
| No
| None

| url
| A URL pointing at a PMTiles archive. The server must support range requests. Mutually exclusive with `file` and required if `file` is undefined
| string
| No
| None

|===

Example:

----
provider:
  name: pmtiles
  file: /data/tiles/overture.pmtiles
----
