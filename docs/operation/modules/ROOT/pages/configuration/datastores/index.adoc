= Datastores
:description: The Datastores configuration defines connections to shared resources, primarily databases, that are used by certain providers, analytics modules, caches, and authentication.  Each datastore definition creates a connection pool when the application is running. Like other entities, the datastores configuration uses a parameter called "name" to dictate the type of datastore which controls the specific list of configuration parameters available. Every datastore configuration must also have an "ID" defined which can be any string and is used by a corresponding provider, analytics, cache, or authentication configuration, usually as a `datastore` parameter.
