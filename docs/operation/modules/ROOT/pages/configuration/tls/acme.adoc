= ACME
:description: Defines a TLS profile that obtains and renews certificates automatically via Let's Encrypt (ACME). Utilizes Go's built-in autocert module under the hood.
:page-eyebrow: TLS
:page-config-name: acme

NOTE: Only usable for xref:configuration/encryption.adoc[`server.encrypt.tls`].

== Description

Using this profile means agreeing to the https://letsencrypt.org/repository/[Let's Encrypt] terms of service. The ACME challenge requires setting xref:configuration/encryption.adoc[`server.encrypt.httpport`].

When running more than one instance, point `Cache` at a directory they all share so each instance doesn't request its own certificate and run into Let's Encrypt rate limits.

Certificates renew on their own. Changes to this profile's parameters can be xref:reloading.adoc#supported-configuration[reloaded]. Hosts that are added get their certificate on the first connection, and certificates for hosts that are removed stop renewing. Changing `Cache` starts from an empty directory unless you move its contents, which means requesting new certificates.

== Example
[tabs]
====
YAML::
+
[,yaml]
----
tls:
  - name: acme
    id: public
    hosts:
      - tiles.example.com
    cache: /var/lib/tilegroxy/certs
----

JSON::
+
[,json]
----
{
  "tls": [
    {
      "name": "acme",
      "id": "public",
      "hosts": [
        "tiles.example.com"
      ],
      "cache": "/var/lib/tilegroxy/certs"
    }
  ]
}
----
====

== Configuration

.Configuration options
[cols="1m,3,1,1,1"]
|===
| Parameter | Description | Type | Required | Default

| ID
| The unique identifier of the profile used to reference this profile elsewhere in configuration. `system` is reserved
| string
| Yes
| None

| MinVersion
| The minimum TLS version to allow. Can be `1.2` or `1.3`. Make sure to quote this in YAML so it isn't read as a number
| string
| No
| 1.2

| Hosts
| The hosts to obtain certificates for and to xref:configuration/encryption.adoc#redirects[redirect] to. Each must be a valid hostname. Wildcards aren't supported
| string[]
| Yes
| None

| Cache
| The path to a directory to cache certificates in
| string
| No
| ./certs
|===
