= Server
:description: Configures how the HTTP server should operate
:page-config-key: server

== Configuration
[cols="1m,3,1,1,1"]
|===
| Parameter | Description | Type | Required | Default

| BindHost
| IP address to bind HTTP server to
| string
| No
| 127.0.0.1

| Port
| Port to bind HTTP server to
| int
| No
| 8080

| RootPath
| The root HTTP Path to serve all requests under.
| string
| No
| /

| TilePath
| The HTTP Path to serve tiles under in addition to RootPath. The defaults will result in a path that looks like /tiles/\{layer}/\{z}/\{x}/\{y}
| string
| No
| tiles

| DocsPath
| The HTTP Path to serve the documentation website under in addition to RootPath. Supply an empty string to disable serving documentation. Ignored when Production is set
| string
| No
| docs

| Headers
| Include these headers in all response from server. For cross-origin headers prefer xref:configuration/cors.adoc[CORS], which can vary the response by request origin. For `Cache-Control` prefer xref:configuration/cache_control.adoc[Cache Control], which derives the value from the layer
| map[string]string
| No
| None

| Production
| Hardens operation for usage in production. For instance, controls serving splash page, documentation, the xref:preview.adoc[layer preview] page, x-powered-by header.
| bool
| No
| true

| Timeout
| How long (in seconds) a request can be in flight before we cancel it and return an error
| uint
| No
| 60

| Gzip
| Whether to gzip compress HTTP responses
| bool
| No
| false

| ShutdownTimeout
| How long (in seconds) the whole shutdown sequence gets. See xref:reloading.adoc[Shutdown]
| uint
| No
| Timeout plus DrainDelay

| DrainDelay
| How long (in seconds) to report unready before draining requests. See xref:reloading.adoc[Shutdown]
| uint
| No
| 5

| TrustedProxies
| IP addresses or CIDR ranges of every CDN, load balancer, and reverse proxy in front of tilegroxy. When a request arrives from one of these, the client IP is taken from `ClientIPHeader`. This is the IP used for xref:configuration/ratelimit/index.adoc[rate limiting], xref:analytics.adoc[analytics], and every log. Never include addresses outside your own infrastructure. In Kubernetes this is usually the pod CIDR of your ingress controller
| string[]
| No
| None

| ClientIPHeader
| The header trusted proxies put the client IP in. For `X-Forwarded-For` the right-most address that isn't itself a trusted proxy is used. Any other header, such as `CF-Connecting-IP` or `True-Client-IP`, must hold a single address. Only used with TrustedProxies
| string
| No
| X-Forwarded-For

| Encrypt
| Configuration for enabling TLS (HTTPS). Don't specify to operate without encryption (the default)
| xref:configuration/encryption.adoc[Encryption]
| No
| None

| TileJSON
| Configuration to turn on endpoints that describe layers using the TileJSON format
| xref:configuration/tilejson.adoc[TileJSON]
| No
| None

| CORS
| Configuration for returning cross-origin resource sharing headers so browsers on other origins can use the tiles
| xref:configuration/cors.adoc[CORS]
| No
| None

| CacheControl
| Configuration for returning a `Cache-Control` header so browsers and CDNs can reuse a tile without asking again
| xref:configuration/cache_control.adoc[Cache Control]
| No
| None
|===
