= Reference

== Available sections

See xref:configuration.adoc[Configuration] for the conventions shared by every section and the top-level structure.

* xref:configuration/layer.adoc[] for the layers to serve and how each one is set up.
* xref:configuration/provider/index.adoc[] for where a layer's tiles come from.
* xref:configuration/cache/index.adoc[] for where tiles are stored once they've been fetched.
* xref:configuration/authentication/index.adoc[] for how incoming requests are authenticated.
* xref:configuration/analytics/index.adoc[] for where usage events are recorded.
* xref:configuration/datastores/index.adoc[] for shared connections used by caches, providers, authentication, and analytics.
* xref:configuration/secret/index.adoc[] for pulling sensitive values from an external store.
* xref:configuration/server.adoc[] for how the HTTP server operates, including encryption, TileJSON, CORS, and cache control headers.
* xref:configuration/health.adoc[] for health check endpoints served on a separate port.
* xref:configuration/client.adoc[] for how requests to upstream HTTP servers are made.
* xref:configuration/log.adoc[] for application, access, and audit logs.
* xref:configuration/telemetry.adoc[] for OpenTelemetry metrics, logs, and traces.
* xref:configuration/error.adoc[] for how errors are returned to users.
